# D-053 — Verification outputs identical to the old project's (owner 2026-11-23)

Date: 2026-11-23
Owner decision: owner message 2026-11-23 (translated): "make the outputs of run_full_verification in the torch project IDENTICAL to the old project's: in what is printed, the plots and the numbers; any difference in cost, stop or bootstrap unit must become an explicit option that can be set to match; the torch default stays as it is."
Why: the verification table matched the old verdicts only approximately (cost, stop width, bootstrap unit, label clip, candle draws, text); the owner wants a mode in which the numbers and the printed text are the old project's, pinned by a parity test against golden files written by the old code.

## What changes behaviour
- `evaluation.verification.match_old` (False): True sets every choice below to the old project's, charges its 0.08 % round-trip cost (0.0004 per side, instead of `evaluation.battery.cost_per_side`) and leaves out the latest-samples table. Off = today's behaviour.
- `evaluation.verification.lang` ("en"), `stop_width` ("predictive_std"; "student_t" = the old Student-t scale), `bootstrap_unit` ("day"; "timestamp" = the old raw bar time): the same choices one by one. Defaults reproduce the behaviour before this decision.
- The summary rows of block b now list the direction rows of every target first, then the MAE rows (the old order); the report columns `test_days` are named `test_dates` as in the old project (both new in D-052, unreleased).
- The printed heading of the verdict table is `INTEGRATED VERIFICATION` between rules of the old width (text only).

- `nig_timenet_torch.workflow.settings.EvalSettings(verification)`: `VerificationSettings(enabled=True, target_acc=0.65, rr=2.0, stop_mode='nig', n_boot=500, run_candle=True, latest_n=1, latest_coins=3)` -> `VerificationSettings(enabled=True, target_acc=0.65, rr=2.0, stop_mode='nig', n_boot=500, run_candle=True, latest_n=1, latest_coins=3, match_old=False, lang='en', stop_width='predictive_std', bootstrap_unit='day')`
- `nig_timenet_torch.workflow.settings.RunSettings(evaluation)`: `EvalSettings(chunk=20000, health_max_rows=100000, battery=BatterySettings(enabled=True, cost_per_side=0.0008, n_variants=1, day_metrics=False, verdict_trim='best', drop_flat=True, account_books=0), verification=VerificationSettings(enabled=True, target_acc=0.65, rr=2.0, stop_mode='nig', n_boot=500, run_candle=True, latest_n=1, latest_coins=3))` -> `EvalSettings(chunk=20000, health_max_rows=100000, battery=BatterySettings(enabled=True, cost_per_side=0.0008, n_variants=1, day_metrics=False, verdict_trim='best', drop_flat=True, account_books=0), verification=VerificationSettings(enabled=True, target_acc=0.65, rr=2.0, stop_mode='nig', n_boot=500, run_candle=True, latest_n=1, latest_coins=3, match_old=False, lang='en', stop_width='predictive_std', bootstrap_unit='day'))`
