Why: the cross-section term (D-032) could only be ADDED to the per-row NIG / class loss; a rank-only arm had no switch.

## What changes behaviour
- `TrainSettings.base_loss_weight` (in [0, 1], read only while `cross_section_loss` is on; refused otherwise) scales the per-row NIG / class loss before the cross-section term is added (`trainer/trainer.py::Trainer.compute_losses`, total and raw alike); 0.0 trains the rank term alone. Its default 1.0 reproduces every earlier run exactly (the config key is written only when set, so earlier configurations and their run identities are unchanged; tested in `tests/trainer/test_cross_section_loss.py`).
