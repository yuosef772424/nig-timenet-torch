## Principles
- **No silent behaviour change.** A package that changes an output lists it in its decision record and PR (rule
  B1); a refactor proves equal outputs (B2: pins, the baseline fixture, the oracle suites).
- **One concept, one place.** Each package removes a duplicate or a hand-kept list, and a guard test (B3) keeps it
  removed: a scan, a parity test or a ratchet lowered.
- **Re-verify before changing.** The audit rows were written by a cheaper model; the package session reads the code
  of every row it takes and drops the rows that do not hold (as A-01 did).
- **Mechanical work to subagents** (rule A4): renames and repetitive edits with their tests in their own worktree;
  the lead checks the diff and the tests before pushing.
