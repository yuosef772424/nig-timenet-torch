## Summary of the area's overall shape

1. The four packages are small and tidy: no module over 600 lines, one function over 80 (`NigTimeNetV2.__init__`, 129), layer imports respect G7 (core imports nothing; stats only core; model/trainer never import workflow).
2. Dead code is almost absent (whole-repo grep found only `Trainer.batch_indices`, `set_determinism`, `label_scale_state` as test-only; the real orphan is `model/panel.py`).
3. The biggest structural debt is duplication across "parallel implementations": staged loop vs `Trainer.fit` (A-07), two label-scale fitters that silently overwrite each other (A-01), four NIG `alpha - 1` variants (A-11), three copies of the builder option list (A-03).
4. The builder and `Trainer` are the two coupling hubs: `NigTimeNetV2` reads ~45 options and keeps hidden state (`_gid`, `hasattr(self, ...)` toggles); `Trainer.__init__` / `fit` read the whole loss config and combine batching modes by priority instead of validating combinations.
5. Cards are mostly accurate; stale spots are "P34" promises, "mirrors the TF builder", the "ONE place" claim of `fit_scalers`, the selection-metric list, and eight modules with no card at all.
