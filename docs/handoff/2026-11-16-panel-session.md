## 2. The models

### 2.1 Common base
- Architecture: `ModelSettings("nig_timenet_v2", {**ANTI_MEMORIZATION_CONFIG, **RUN_DEFAULT_SWITCHES, **MODEL_FIRST_FIXES})` from `default_model_settings()` in `src/nig_timenet_torch/workflow/settings.py`. In every look and job of this session the encoder was overridden to `gru` (`model_overrides {"encoder": "gru"}`), 32-bar windows of 3 log-move channels (`X_4h` shape (N, 32, 3)), heads: NIG regression (`y_high`, `y_low`, `y_close`) plus binary class heads per price target (`y_*_class`); direction comes from the close head only.
- Heads/targets: high / low / close, label horizon `forecast_horizon` 2 bars of 4h (8 h), `reg_target_mode` return, codec `logret_std`.
- Trainer defaults of the jobs: batch 512 (jobs) or 256 (looks), lr 3e-4, `steps_per_execution` 32 (jobs) or 16 (looks), weight decay 1e-4 (default), seeds 0 and 1, early stop patience 6 (panel-001), 4 (looks), 3 (rolling).
- Code: `workflow/run.py` (steps), `workflow/flat_run.py`, `workflow/panel_study.py` (arms), `jobs/panel.py` (entry `panel`), `jobs/rolling.py` (entry `rolling`), `workflow/rolling_run.py`, `trainer/*`, `model/builder.py`, `model/cross_coin.py`.

### 2.3 "The panel (multi-coin) model"
The same model, trained on whole timestamps: `SplitSettings(cross_section=True, top_coins=N)` makes batches and evaluation chunks hold whole timestamps (trainer/groups.py), the row's timestamp id is one extra input channel. Switches (all OFF by default, D-032):

| switch | where | meaning |
|---|---|---|
| `cross_input: "relative"` (model override) | D-028, `model/cross_coin.py` | each coin's window becomes [own, own minus timestamp mean, (own minus mean) / timestamp sd, mean] bar by bar |
| `cross_coin_layers`, `cross_coin_kind` `attention` / `mean` | D-028 | block after the trunk; looks showed no gain over relative inputs |
| `cross_center: true` (model override) | new | the close mean is returned minus its timestamp mean (high / low not centred) |
| `TrainSettings.cross_section_loss` `none` / `ic` / `rank_ic`, `cross_section_weight` | new, `trainer/cross_section_loss.py` | 1 minus the mean over timestamps of the correlation of the NIG means with the label (or its rank) inside the timestamp; needs `split.cross_section` |
| `selection_metric: "val_rank_ic_reg"` / `"val_ls_sharpe_close"` | new in `trainer/selection_metric.py` | rank IC of the regression head / per-timestamp Sharpe of the top-bottom 20 % book |
| `TrainSettings.direction_balance` (weight) + target names | new, `trainer/direction_balance.py` | penalises a batch whose predictions lean long or short; for the close heads only |
| `BatterySettings.day_metrics`, `RollingConfig.day_metrics` | new | also write winning-day metrics (`eval/day_metrics.py`) |

Named arms of `workflow/panel_study.py` (`ARMS`): `per_coin` = {} (baseline arm), `relative` = `cross_input: relative`, `relative_rank_loss` = relative + `cross_section_loss: rank_ic`, `relative_rank_loss_center` = relative + `cross_center` + rank_ic, `relative_rank_loss_ls` = relative + rank_ic + selection `val_ls_sharpe_close`. `PanelConfig.arms` default = all five in the order of the dict in the pins; `panel-001` runs four (no `_ls`), the smoke all five.
